# 两面 · 宣传素材包

本目录包含可直接用于项目主页、赛事提交与社交媒体的品牌素材，视觉沿用产品设计 Token：白底玻璃光幕、墨色文字、蓝（#2E80A8）到琥珀（#BA8A42）的取向光谱。

| 文件 | 尺寸/格式 | 用途 |
|---|---|---|
| `two-sides-logo.svg` | 1024 × 1024 SVG | 项目 icon、赛事头像、深浅背景均可缩放 |
| `two-sides-mark.svg` | 512 × 512 SVG | favicon、导航栏、头像小尺寸标记 |
| `two-sides-poster.png` | 1600 × 900 PNG | 官网封面、演示视频封面、赛事项目封面 |
| `two-sides-social.png` | 1200 × 675 PNG | 社交媒体分享图 |

SVG 使用系统中文字体回退（Noto Serif SC / SimSun）和 Inter 英文回退，网页部署时建议配合现有自托管字体。PNG 已嵌入文字，可直接发布。
