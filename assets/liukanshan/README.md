## 使用规范（工程侧）

1. **体积**：每个 GIF 约 1MB，**禁止进首屏、禁止多只同时循环**。只在对应状态挂载，配 `loading="lazy"`；组件卸载即释放
2. **压缩**：入库 `apps/web` 前先处理——`gifsicle` 降帧到 10fps、缩到 160–200px，或转 WebP 动图（体积可降 60–80%）
3. **KSMark（N3「看山解读」16px 标识）**：从合板裁正面头部区域 → 抠底 → 输出 16/32/64px 三档 PNG；**不要直接缩放整张 jpg**
4. **配色**：看山是黑白形象，与产品白底天然兼容；不要给它上品牌色
5. **演示视频**：可用动图增加记忆点，但注意提交检查项——画面里不能带出任何凭证信息
